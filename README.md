# 青出于蓝 · 山东蓝印花布草木染 3D 交互终端

一个单文件网页 + ESP32 硬件的交互装置：把山东蓝印花布的草木染工艺做成可以亲手玩的 3D 体验——选版、刮浆、下缸浸染、起缸发色、复染、除浆，全流程用真实传感器驱动。

> Shandong blue-calico (indigo) dyeing, as a hands-on 3D interactive terminal. One HTML file + one ESP32 sketch.

## 能玩什么

- **五步染布流程**：0 选版刮浆 → 1 下缸浸染 → 2 起缸发色 → 3 复染决策 → 4 除浆导出。刮浆要刮满 6 遍，浸染、发色都有真实计时。
- **7 个预设纹样**：连年有余、喜鹊登梅、榴开百子、牡丹富贵、莲生贵子、蝶恋花、葡萄——都是山东蓝印花布的经典题材，繁复的民间风格，纹样里没有汉字。
- **导入照片变印花**：导入一张自己的照片，程序自动简化、转成蓝白两色的印花，染出来的就是照片里的内容（思路和无人机点阵 SkyWeave 一样：图片变图案）。
- **摇杆多视角**：推摇杆可以转动布的观察角度（水平 ±60°、俯仰 ±30°），布跟着视角走，不会穿模。
- **真实硬件驱动**：光敏电阻（掀盖见氧）、电位器（刮浆）、两个按键（切换纹样 / 确认）、双轴摇杆（转布），全部接在 ESP32 上，通过 Web Serial 和网页实时通信。

## 硬件（ESP32-WROOM-32E）

| 元件 | 引脚 |
| --- | --- |
| 光敏电阻 | IO34 |
| 刮浆电位器 | IO35 |
| 蓝帽按键（切换纹样） | IO14 |
| 黄帽按键（确认 / 除浆） | IO27 |
| 摇杆 X / Y | IO32 / IO33 |
| 摇杆按下 | IO25 |

串口：115200 波特率，CSV 格式 `光敏,电位器,蓝键,黄键,摇杆X,摇杆Y,摇杆按下`，约每 35ms 发一包。

## 怎么用

1. 把 `firmware/ESP32_indigo_controller.ino` 烧进 ESP32（Arduino IDE 打开，开发板选 ESP32-WROOM-32E；.ino 文件要放在同名文件夹里）。
2. 按上面的表接好传感器。
3. 用 Chrome 或 Edge 打开 `index.html`（直接双击也行），点“连接串口”，选 ESP32 的端口。
4. 按屏幕提示走：选纹样 → 刮浆 6 遍 → 合盖入缸 → 浸满 6 秒掀盖 → 透氧 10 秒 → 除浆导出。

## 文件

- `index.html` —— 整个网页程序（Tailwind + Three.js，CDN 引入，单文件，离线可用）
- `firmware/ESP32_indigo_controller.ino` —— ESP32 固件（读传感器、串口发 CSV）
